# 子授渔留学官网

纯静态展示网站，无需构建、无第三方依赖，可直接部署到任意静态托管平台。

## 目录结构

```
子授渔留学官网/
├── index.html   页面结构与文案内容
├── styles.css   样式（响应式、动效）
└── script.js    交互逻辑（导航、滚动动效、表单校验）
```

## 本地预览

在本目录下启动一个静态服务器即可，例如：

```bash
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

也可以直接双击 `index.html` 用浏览器打开。

## 部署

本项目是纯前端静态文件，可以直接部署到：

- GitHub Pages
- Vercel / Netlify（无需构建命令，输出目录设为本目录即可）
- 任意云厂商的静态网站托管 / 对象存储

## 后续可扩展

- 联系表单目前仅做前端校验并展示提交成功提示，如需真实收单，可接入表单服务
  （如自建接口、Formspree 等），将 `script.js` 中 `contactForm` 的提交逻辑
