# 总纲/细纲 ——《我请假奔丧，老板让我直播守孝》

## 故事一句话
直播带货公司的运营周明请三天丧假，老板却嗅到"真情绪=真流量"的商机，要他直播守孝冲业绩。周明表面照办，暗地里用老板最信的那套流量与合规规则，把这场荒诞直播变成压垮公司的最后一根稻草。

## 主题内核
有些情不能带货，有些事不能直播。
你教我用流量杀人，我就用流量，先杀你。

## 题材定位
黑色职场讽刺 + 爽感反杀。开局荒诞炸裂，中段步步加码，后段制度反杀，收口克制催泪。

## 创意约束
- 反套路：周明从不撕逼、不骂街、不违规。他每一步都"完美执行老板的要求"，而正是完美执行，让老板社死。爽点来自"按你说的办，办到你哭"。
- 硬约束：
  1. 全文约12000字，共8章，每章约1400-1600字；
  2. 第一人称（周明）；文风铁律：通篇短句，对话不加引号，禁用破折号，白描多分段；
  3. 公司、平台、品牌方均虚构（星澜传媒、橙信、各品牌方），不影射真实企业个人；
  4. 制度逻辑自洽：丧假受法律与公司制度保护；"直播守孝"踩的是公序良俗+强迫劳动+平台内容规范三条红线；反杀靠录音、聊天记录、平台举报、品牌方避险、舆论共情，不靠主角开挂或暴力；
  5. 爷爷这条情感线必须真，压住全篇的荒诞，让讽刺有重量。

## 人物核
- 周明：28岁，星澜传媒运营兼小主播。爷爷一手带大。缺陷：太能忍，总把老板的离谱当成"还能商量的事"。成长弧：从"我忍一忍把假请下来"到"我不忍了，按规矩办，办死你"。
- 爷爷周长生：评书艺人，撂地说了一辈子书。口头禅：台上无真情，台下没人听。生前最看不上"假买假卖假哭"。遗物：一把醒木、一件说书大褂。情感锚。
- 田耀祖（田总）：星澜老板。流量原教旨主义者。名言：人没了，流量不能停。不是脸谱反派，是真信"万物皆可带货"的怪物。
- 康丽（K姐）：周明主管。夹在中间的执行者，自己也被PUA，几次良心闪烁，最终倒戈。
- 林雯：公司摄像/剪辑，周明的同盟。手里那台机器，最后拍下的不是周明要的素材，是田总要的证据。
- 网友/平台：真正的武器。

## 八章细纲

### 第1章 节哀，顺便
- 开场炸点：殡仪馆告别厅，周明守在爷爷遗体边。手机震动，田总微信弹出：明哥节哀。顿号。然后第二条：不过我有个想法，能让爷爷走得更有价值。第三条：咱直播。
- 周明以为田总喝多了。回拨电话，田总在那头精神得很，越说越兴奋：你这是真悲伤，真情绪，全网都缺这个！咱不卖货，先做共情，养号，后面变现。情感赛道，蓝海！
- 闪回：三天前请丧假。HR小赵卡流程，田总批了，附一句"假可以请，但咱们能不能创造点价值"。周明当时没往心里去。
- 周明拒绝。田总改口"建议"变"安排"：本月绩效考核，团队需要一个爆款，你不上，K姐顶。话里有刀。
- 章末钩子：周明低头看爷爷。大褂口袋里露出半截醒木。他忽然想起爷爷那句，台上无真情，台下没人听。他打字回田总：行，我播。

### 第2章 这流量，爷爷给的
- 田总连夜拉群"周明爷爷·情感专项",安排林雯扛机、康丽盯数据、运营写脚本。脚本离谱：守孝第一日泪点设计、品牌口播预留位、弹幕引导话术。
- 周明表面全配合，提一个条件：直播内容我说了算，因为只有真的才有流量。田总最爱听"真",当场答应，还白纸黑字发群里（埋证据）。
- 首播。周明没卖惨，没带货。他披上爷爷的说书大褂，拿起醒木，啪一声，开讲：今天这场书，叫《我爷爷》。
- 他平静讲爷爷撂地说书一辈子、如何把他养大、临终前的话。不哭天抢地，全是细节。在线人数疯涨。田总在后台狂喜，刷一排红包：对对对就是这个感觉！
- 章末钩子：涨到十万人时，田总在群里下指令：情绪到位了，上链接，殡葬好物专场，孝心三件套。周明看着指令，笑了。

### 第3章 上链接
- 周明当着十万人面，平静念出后台刚发来的指令原文：刚收到公司通知，让我现在上链接，卖孝心三件套。
- 他停顿。然后说：我爷爷撂地一辈子，最恨假买假卖。我不卖。
- 弹幕炸了。直播间瞬间变成大型共情现场，全网开始问：什么公司，逼员工直播守孝带货？
- 田总后台懵了，急令断播。林雯"手滑"没断，多播了四十秒——正好录下康丽冲进来传达的原话：田总说了，不卖就算旷工。（证据二）
- 话题冲上热搜：直播守孝。星澜传媒被扒。
- 章末钩子：周明手机炸了。一条私信置顶：橙信平台·商务合作部。

### 第4章 甲方爸爸先跑
- 误以为是机会，其实是雪崩开始。品牌方连夜解约：我们的产品不能和"逼员工直播守孝"绑一起。星澜三个大单一夜蒸发。
- 田总变脸，把周明叫回公司（视频会议）。先扣帽子：你私自篡改脚本，损害公司形象，要赔偿。
- 周明不慌，摆出三样东西：批假记录、群里"内容我说了算"的白纸黑字、康丽那句"不卖就算旷工"的录音。
- 田总气急，说出关键一句：一个破直播你较什么真，人都死了还能怎样。被林雯的机器拍下。（证据三，致命）
- 章末钩子：康丽找到周明，递来一个U盘，声音发抖：还有这些，你可能用得上。

### 第5章 K姐的U盘
- U盘里：田总历年PUA语录、克扣丧假产假的内部聊天、把员工痛苦做成流量的"选题库"截图。康丽自己也是受害者，孩子住院她被要求边输液边开会。
- 周明没有立刻爆。他做了一件最"职业"的事：按公司流程，正式走仲裁+平台举报+媒体核实，一步不越线。
- 平台介入：星澜账号矩阵因"违背公序良俗、诱导消费"被封禁限流。律师函满天飞。
- 田总反扑，买水军带节奏：周明炒作、吃人血馒头、消费爷爷。一时舆论拉锯。
- 章末钩子：周明决定再播一场。这一次，不是为流量。

### 第6章 最后一场书
- 周明开了人生最后一场直播。还是大褂，还是醒木。
- 他不回应骂战，不卖惨。他把爷爷完整的一生说成一段书，从撂地、挨饿、收徒、到把孙子供成大学生。最后一句：我爷爷说，台上无真情，台下没人听。我今天，没演。
- 啪。醒木一收，下播。不带货，不引流，不留链接。
- 这场"反流量"的直播，成了真正的顶流。全网共情封顶，水军溃散。田总买的热搜被反向做成证据。
- 章末钩子：仲裁结果与平台处罚同日下达。星澜，凉了。

### 第7章 数据不会骗人
- 清算章。星澜传媒被平台全面封禁，品牌集体解约，资金链断。田总名下另两家公司被牵连。
- 仲裁支持周明：违法安排丧假期间劳动、强迫，公司赔偿。康丽等一批员工跟进维权。
- 田总最后来找周明，不是道歉，是谈合作：你现在这么火，咱重新签约，分成好谈。他到死都只懂流量。
- 周明把爷爷的醒木放在桌上，啪一声。说了全书最狠的一句平静话：田总，您教我的，我都学会了。数据不会骗人——您没了。
- 章末钩子：周明交了辞呈。走出星澜，手机里爷爷的旧照片，笑着。

### 第8章 不直播了
- 收口克制。周明没成大网红，关了打赏，停了直播。
- 他回老家，接手爷爷撂地的那个旧书场，免费给老人孩子说书。偶尔有人举手机要拍，他笑着按下去：这个，不直播。
- 尾声：田总的公司清算公告刷过去，没人记得了。周明把那把醒木和爷爷的大褂，并排放进玻璃柜。
- 最后一段（核心句）：有人问我，你后悔把事情闹这么大吗。我说，我没闹。我只是按他说的，认真播了三场。
  有些情不能带货。有些事，不能直播。
  我爷爷说得对，台上无真情，台下没人听。
  我没演。所以他们都听见了。
