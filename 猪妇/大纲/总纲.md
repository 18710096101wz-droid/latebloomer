# 总纲 ——《猪妇》（v3 重大调整版）

## 故事一句话
被婆家用体重和生育羞辱的女人，靠自救、事业和真相反杀，重新拿回身体、饭碗和人生。

## 三条反杀主线（一切情节围绕此展开）
1. **身体反杀**：她不是懒、馋、胖，而是被高糖高油偏方、羞辱、"备孕不准动"的错误照顾拖垮的。停掉偏方、规律生活后身体逐步恢复。
2. **事业反杀**：她不是突然会赚钱。婚内三年按克数给前夫调理胃病、用八百块伙食钱养活四口人，控成本、懂食疗的本事早就在身上。创业四步走：医院门口病号餐 → 健身房试吃 → 写字楼团餐 → 前夫公司行政慕名下单。
3. **真相反杀**：不孕的责任不一定在她。医生从一开始就说要夫妻同查，男方长期逃避检查，最后被医学报告（严重弱精，几乎无自然生育能力）当众打脸。

## 创意约束
- 反套路规则：女主全程不主动复仇。前夫一家的崩塌由自身谎言驱动：逃避检查、断章取义、新妻外遇、亲子鉴定爆雷。
- 硬约束：
  1. 每章约1400-1500字，共13章约2万字；
  2. 第一人称女主视角；文风铁律：通篇短句，对话不加引号，全文禁用破折号，白描多分段；
  3. 成人向尺度内点到为止；
  4. 医学逻辑：医生原话必须专业留有余地（"体重确实影响排卵和内分泌，但不孕不能只查女方，建议夫妻双方系统检查"），歪曲事实的是婆婆；男方为严重弱精（非无精），病根早就存在，乱补只是加重和遮掩；掉秤节奏为第一个月十二斤（大半是水肿），三个月共瘦三十斤；
  5. 结尾不靠生育证明女主赢。删除一切"多胎抱子"式胜利。她赢在不再用肚子证明自己。

## 人物核
- **林小满**：缺陷是自卑与习惯性忍让。本事是做饭、控成本、照顾人。成长弧：把最好的本事从"喂给不值得的人"转向"喂养自己的人生"。
- **陈嘉明**：懦弱、妈宝、虚伪、习惯被照顾。不深情、不洗白。口头禅式台词：妈也是为你好，你忍一忍。后期求女主不是因为爱，是因为失去了免费保姆、情绪垃圾桶和体面婚姻。点题台词：我不是非要孩子，我是受不了没人管我。
- **王翠凤（前婆婆）**：断章取义的执行者。医生没冤枉女主，歪曲事实的是她。砂锅的最终定性：没养出孙子，只养出她儿子的遮羞布。
- **周衍**：不是天降霸总。严重胃病（应酬喝出来的），普通外卖吃完就疼；胃病发作时被女主的粥救过；先看中的是她的产品和韧性，不是脸。第6章只谈投资不谈恋爱，合同最后一页亲手加一条：乙方不得再被任何人用体重羞辱。感情线到第13章自然落地。
- **蜜蜜（前夫新妻）**：怀得太快，胎数太巧。与陈嘉明的顶头上司、销售总监雷某关系暧昧。三胞胎亲子鉴定爆雷的引线。
- **雷总监**：陈嘉明的直属上司（注意：不是周衍，周衍是总裁），亲子鉴定的另一方。
